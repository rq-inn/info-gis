What You Can Do

地図を、ただの画像ではなくプレイ面に変える。

GloranthaGIS は地理情報を、卓のみんなが読んで判断できる情報に変換します。

Place Jump

日本語でも英語でも地名検索して、その場所へすぐにジャンプできます。

Distance Measurement

ルートを引いて、地点間の距離を実感のある長さで確認できます。

Range Circle

半径ツールで移動圏、勢力圏、効果範囲を視覚化できます。

Layer View

PNG地図を読み込み、ズーム、ドラッグ、レイヤー感覚で世界を見渡せます。

Distance Origin Flag

青い基準旗を置いて、画面中心からの南北東西距離を読み取れます。

Built For Play

実際のセッション中に使うことで、移動や地理の感覚が一気に具体的になります。

How to Start

3ステップですぐ始める。

最初の体験は、技術的ではなく直感的であるべきです。

1

地図を用意

使いたい高解像度の Dragon Pass や Prax 地図を準備します。

2

PNGを読み込む

GloranthaGIS を開き、アプリ画面から PNG ファイルを読み込みます。

3

探索して遊ぶ

ズーム、距離計測、経路比較をしながら、セッションの中でそのまま使います。

Use Cases

卓で効く場面を、先に想像させる。

機能説明だけで終わらず、実際のプレイで役立つ絵が見えるようにします。

Travel Planning

今どこにいて、どこへ向かい、その旅がどれほどの意味を持つのかを共有できます。

Route Decisions

道、川、山脈、距離を並べて比較し、グループ全体で進路判断できます。

Range And Area

勢力圏、危険地帯、移動スケールを円と距離で理解できます。

Session Immersion

地図は背景絵ではなく、会話そのものを支える道具になります。
